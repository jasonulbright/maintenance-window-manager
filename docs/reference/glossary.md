# Glossary

This page defines the terms of Maintenance Window Manager.

## What it does

It explains the terms that the tool and this guide use.

## When to use it

Use it when a term is not clear.

## Requirements

None.

## Terms

| Term | Meaning |
|---|---|
| Built-in collection | A collection that the site makes. Its ID starts with `SMS`. |
| Device collection | A group of devices on the site. |
| Maintenance window | A time span in which a collection may restart devices and install software. |
| Recurrence | How often the window repeats: one time, daily, weekly, monthly by date, monthly by weekday or Patch Tuesday. |
| Patch Tuesday | The second Tuesday of a month. A schedule can start a number of days after it. |
| Coverage | The state of a collection: it has a window or it has none. |
| Template | A saved schedule in `Templates` that you apply to collections. |
| Window type | Which deployments the window applies to: any, software updates only or task sequences only. |
| SMS Provider | The server role that gives access to the site data. |
