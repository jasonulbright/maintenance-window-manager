# Keyboard

This page lists the Tab order and the keys of Maintenance Window Manager.

## What it does

Every control can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

### Tab order of the Windows view

Select the **Windows** button in the sidebar, then press Tab. The focus goes in this order:

1. The sidebar buttons: **Coverage**, **Templates**, **Options**.
2. **Refresh**.
3. The filter box and the status list.
4. **Export CSV** and **Export HTML**.
5. The grid, one cell after the other.

### Keys

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Up, Down | Move in a grid or a list. |
| Esc | Close a dialog, as **Cancel**. |

## Limits

- The Tab order of the other views follows the layout.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A button is skipped. | The button is disabled. | Select a row first. |
