# Maintenance Window Manager documentation

Maintenance Window Manager creates and manages the maintenance windows of Configuration Manager device collections. This page links every page of the documentation.

## Start

- [Getting started](getting-started.md): install, set the connection and load the windows.

## Core

- [Windows](core/windows.md): every maintenance window of every collection, and New, Edit, Toggle Enabled and Remove.
- [Schedule editor](core/schedule-editor.md): the recurrence options and the preview of the next five occurrences.
- [Coverage](core/coverage.md): the collections that have no window, and Apply Template for several collections.
- [Templates](core/templates.md): the saved schedules, and New, Edit, Delete and Apply.
- [Options dialog](core/options.md): Connection and About, and the theme.
